# ITV plc — Capital Structure & Financing Options Analysis

## Analysis date
15 September 2026. Financial information available as of this date.

## Core question
Is additional external financing required over the next three years, and if so, what financing strategy best balances liquidity, leverage, shareholder returns and financial flexibility?

## Status
Work in progress — data collection phase.

## Methodology
This project analyses ITV plc's capital structure, debt maturity profile and financing options using primary-source investor materials. The model determines the recommendation; no conclusion is predetermined.
